## 在 VPS 上用 Docker 部署 n8n：完整步驟

部署本身沒有難度，指令都能整段複製，從開機到打開 n8n 編輯器，十幾分鐘內可以完成。

**1. 連線與環境準備**

SSH 進 VPS（RackNerd 開通後會寄上 IP 與 root 密碼），先更新系統套件，再安裝 Docker 與 Docker Compose。

**2. 建立專案目錄與設定檔**


mkdir ~/n8n && cd ~/n8n
nano docker-compose.yml


貼入以下內容（時區依需求調整）：

yaml
services:
  n8n:
    image: docker.n8n.io/n8nio/n8n:latest
    container_name: n8n
    restart: unless-stopped
    ports:
      - "5678:5678"
    environment:
      - GENERIC_TIMEZONE=Asia/Taipei
      - TZ=Asia/Taipei
    volumes:
      - ./data:/home/node/.n8n


`volumes` 這行是重點：工作流、憑證、內建資料庫全都存在掛載出來的 `./data` 目錄，之後升級、搬家都靠它。

**3. 啟動並確認**


docker compose up -d
docker compose logs -f --tail=50


**4. 註冊管理員帳號**

瀏覽器打開 `http://伺服器IP:5678`，設好帳號密碼就進入編輯器了。

**5. 綁網域與 SSL**

把網域的 A 記錄指向 VPS IP，用 Caddy 或 Nginx 做反向代理，把 443 流量轉到 5678，並簽發 Let's Encrypt 憑證。之後所有 Webhook 都走這個網址。

**6. 日後更新**


docker pull docker.n8n.io/n8nio/n8n:latest
docker compose up -d


更新只建議追官方標示的穩定版，別為了搶新版讓線上流程冒相容性風險。

順帶一提：自架版註冊後，n8n 曾提供限時免費的企業版功能加成——24 小時內的工作流版本歷史、進階除錯、執行紀錄的搜尋與標籤。到 Settings > Usage & Plan 輸入信箱收到的序號即可啟用，條件是版本 1.66.0 以上；照上面步驟裝的最新穩定版自然滿足。註冊時留意畫面提示就好。

## 上線前建議做完的五件事

自架不等於裸奔上線，這五項都算一次設定、長期受益：

1. **反向代理＋SSL**：上面第 5 步沒做的先補上，Webhook 和 API 傳輸都需要加密連線。
2. **開啟 2FA**：n8n 介面右上角帳號區進入設定即可開啟。自架環境裡存著 Gmail、Notion、資料庫等大量第三方授權憑證，這一步別省。
3. **資料庫外接 PostgreSQL**：流程一多，內建資料庫會撐不住併發，在 compose 的環境變數裡用 `DB_*` 參數指定外部資料庫即可。
4. **自動備份**：一行指令打包整個資料目錄，丟進 cron 每天跑一次：
   
   docker run --rm -v ~/n8n/data:/data alpine tar czf /data/backup_$(date +%F).tar.gz /data
   
5. **定期升級**：配合上面的更新指令，固定每幾週拉一次穩定版，順手看一眼官方 release notes 有沒有破壞性變更。

## 三個最常見的坑

| 症狀 | 常見原因 | 解法 |
| --- | --- | --- |
| Webhook 回傳 404 | 工作流右上角的啟用開關沒打開 | 啟用工作流即可 |
| 容器反覆重啟 | data 目錄權限錯誤，或 5678 埠被占用 | `chown -R 1000:1000 data/`，或換一個埠號 |
| 編輯器載入很慢 | VPS 的 CPU／記憶體不足 | 升級到 2 vCPU / 4GB RAM |

排程類工作流的執行時間如果跟預期對不上，先檢查 compose 裡的 `GENERIC_TIMEZONE` 有沒有設成你的時區——定時觸發的基準時間就是它管的。

## 自架 n8n 常見問題

**自架版的「無限執行」是真的嗎？**

是真的。自架授權下，工作流執行次數、單一工作流的步驟數、共享專案數都不設上限；實際天花板是伺服器硬體，這也是前面建議正式使用至少 2GB RAM 的原因。

**完全不會 Linux 指令，還能自架嗎？**

能。Docker 部署的指令都能整段複製貼上，出錯點通常只有權限和埠號兩種（見上表）。真的連終端機都不想開，就走 PaaS 一鍵部署，代價是每月固定月費，例如 Zeabur 開發者方案的每月 5 美元。

**機房位置會影響 n8n 嗎？**

會，主要兩個層面。AI 節點方面，OpenAI API 不支援部分地區，選美國或歐洲機房直接避開；延遲方面，編輯器是你自己的瀏覽器在連，選離你近的節點操作體感更順。

**資料放在哪？想換供應商怎麼辦？**

全部在掛載出來的 data 目錄，對應容器內的 `/home/node/.n8n`。備份就是打包這個目錄；想搬到新 VPS，把目錄帶過去、重新 `docker compose up -d` 就完成。這是自架相對 PaaS 最實在的主控權。

**需要另外買網域嗎？**

純本機或內網測試不用；工作流要用 Webhook 接外部事件、要簽 SSL，網域就是必備，一年數百元台幣的開銷。
